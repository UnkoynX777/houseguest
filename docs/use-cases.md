# Use cases

These are situations Houseguest is designed for. Each assumes the guest uses a separate standard Windows account.

## Lending your PC for an hour

Start from the **Guest** profile: Windows components and Windows-signed programs are allowed, administrator tools such as the command prompt, PowerShell, the registry editor and Task Manager are blocked, and everything else is blocked until you allow it. Add the browser from **Applications**, then use Preview to check the result.

## A child who needs the PC for homework

Create a profile that allows the browser and the office suite only. Use a four-hour session and "Lock the guest out" when time is up. The history shows which programs were attempted.

## A game night

Start from the **Gaming** profile, which blocks administrator tools, and add the launcher and games you want from **Applications**. Extend the session from the dashboard when needed.

## Letting a coworker present from your laptop

Allow the presentation tool and the browser, block everything else, and use a 30-minute session. Temporary exceptions let you allow one more program for 15 minutes without editing the profile.

## Seeing what would be blocked

Turn on **Audit mode**. Houseguest records what it would block without stopping anything, so you can tune a profile before enforcing it.

## What it is not for

Houseguest is not a replacement for managed device policy in an organisation, not a defence against a local administrator, and not a way to hide software from a user who owns the machine.
