# Support

- **Questions and ideas:** [GitHub Discussions](https://github.com/UnkoynX777/houseguest/discussions).
- **Bugs:** open an issue using the bug template and include the Diagnostics report (Diagnostics → Copy report).
- **Security problems:** see [SECURITY.md](SECURITY.md). Do not use public issues.
- **Locked out?** From an elevated prompt run `houseguest-cli recover`. If the service is unreachable, boot to Safe Mode and uninstall Houseguest from Installed apps.

This is a volunteer project; there is no guaranteed response time.
