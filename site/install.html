Install Houseguest

Windows 10 or 11 (x64). Verified so far only on Windows 10 Pro 22H2.

  1. Download Houseguest-<version>-x64.msi and SHA256SUMS.txt from the latest release.
  2. Verify the download: sha256sum -c SHA256SUMS.txt, or compare (Get-FileHash .\Houseguest-*.msi).Hash with the file. Releases also carry a provenance attestation: gh attestation verify <file> --repo UnkoynX777/houseguest.
  3. Run the installer as administrator. Builds are currently unsigned, so SmartScreen may warn you.
  4. Open Houseguest, set an owner PIN, create a standard Windows account for your guest, then use Sessions → Preview → Start protection.
WebView2. The interface needs the Microsoft Edge WebView2 Runtime. If it is missing Houseguest offers the official Microsoft download page. Protection and the command line do not need it.

Recover or uninstall

houseguest-cli recover               # end the active session (elevated prompt)
houseguest-cli recover --reset-owner # also clear the owner and PIN
msiexec /x Houseguest-<version>-x64.msi FORCE_UNINSTALL=1   # uninstall during an active session

While a guest session is active the uninstaller stops with an error, so a session is not removed by accident. Administrators always keep this path. Settings and the audit log stay in %ProgramData%\Houseguest until you delete the folder.
