Frequently asked questions

What is Houseguest?

An open-source Windows app blocker for guest sessions. The owner of a PC decides which programs a guest account may run for a set time, and a Windows service enforces the rules independently of the interface.

Does it block programs before they start?

No. It terminates a program shortly after Windows reports that it started. A blocked program can run for a moment, and a very short-lived program can finish before it is stopped.

Can the guest turn it off?

A standard user cannot stop the service, edit its data, read the audit log, claim ownership or uninstall it. A local administrator can always remove it, by design. Give guests a standard account.

Does it work on Windows 11 or modified builds such as Ghost Spectre?

Only Windows 10 Pro 22H2 has been tested. Houseguest probes the machine at run time and degrades when a component is missing, but it does not claim support for systems that have not been verified.

Does it use AppLocker, App Control or Windows Defender?

No. It uses its own process supervision so that behaviour is the same on every edition.

Does it collect data?

No telemetry, no accounts. The only network request is an optional update check that you trigger yourself.

Is the installer signed?

Not yet. Verify downloads with SHA256SUMS.txt and the GitHub build provenance attestation.
