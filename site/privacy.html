Privacy

Houseguest runs entirely on your computer.

  • No telemetry, accounts or analytics. Nothing is sent anywhere automatically.
  • One optional request. About → Check for updates asks the public GitHub API for the latest release.
  • Local data. Settings, profiles and the audit log live in %ProgramData%\Houseguest, readable only by administrators. Delete the folder to remove them.
  • Interface data. Window position, theme and notification preferences stay in your Windows user profile.
  • No secrets in logs. The owner PIN is never stored or logged; only a salted PBKDF2 verifier is kept.

This website is static pages without cookies or analytics scripts. Full policy: docs/privacy.md.
